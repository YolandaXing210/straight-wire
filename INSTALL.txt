Straight Wire — straight, circuit-board style wires for Grasshopper
===================================================================

Draws Grasshopper's wires as right-angle or 45° traces, each in its own lane,
around components. Requires Rhino 8 (Windows or macOS).

Free to use, for any purpose. Please do not redistribute it - share the
download page instead. See LICENSE for the full terms.


INSTALL
-------

macOS
  1. Copy StraightWire.gha into:
     ~/Library/Application Support/McNeel/Rhinoceros/8.0/Plug-ins/
        Grasshopper (b45a29b1-4343-4035-989e-044e8580d9cf)/Libraries/

     Quick way to open that folder: in Grasshopper, File > Special Folders >
     Components Folder.

  2. If macOS blocks it, open Terminal and run:
     xattr -d com.apple.quarantine "<path to StraightWire.gha>"

  3. Restart Rhino.

Windows
  1. RIGHT-CLICK StraightWire.gha > Properties > tick "Unblock" > OK.

  2. Copy it into:
     %APPDATA%\Grasshopper\Libraries\

  3. Restart Rhino.

  Straight Wire runs on Rhino's default .NET runtime. If you switched Rhino to
  .NET Framework (the SetDotNetRuntime command), switch it back to NETCore.


USING IT
--------

  Straight Wire menu > Curve / Orthogonal / 45°
      With nothing selected: the style of every wire in this file.
      With components selected: only the wires touching them.
  Straight Wire menu > Wire Edit Mode   Toggle mouse editing; OFF at each startup.
                                         Session-only; shared by all canvases.
  Straight Wire menu > Wire Spacing      Gap between neighbouring lanes.
  Straight Wire menu > Follow Global     Selected wires go back to the file's style.
  Straight Wire menu > Save to This File Store the styles in the .gh, so anyone with
                                         Straight Wire sees the same wires.
  Straight Wire menu > Make This My Default
                                         Use this style for files with none of their own.
  Buttons in the canvas's bottom-left    The same three styles. Hide them from
                                         Grasshopper's canvas widget menu.
  Alt+1 / Alt+2 / Alt+3                  Curve / Orthogonal / 45° (Option on a Mac).
  Straight Wire menu > Reset Selected Wires
                                         Selected wires lose their hand edits.

EDITING WIRES
-------------

  First enable Straight Wire > Wire Edit Mode. Turning it OFF clears temporary
  selection and cancels an unfinished drag, preserving saved points and styles.
  OFF double-clicks insert native Relays on visible wires, including edited routes.
  Overlapping connections show a selection menu; cancel makes no changes.
  An invisible superseded Curve opens search instead of inserting a Relay.
  Single-click, hover and drag remain passive while OFF. Components and grips
  retain native interactions. Inserting a Relay is one Undo/Redo step.

  Hover a wire                           It highlights.
  Click a wire                           Selects it (Shift-click adds or removes).
                                         Click anywhere else or press Esc to clear.
  Drag the middle of an automatic wire   Slides its lane; the others make room.
  Drag a bend handle                     Moves that point; the wire becomes
                                         hand-drawn. Points snap to 0/45/90-degree
                                         lines and the grid; hold Option (Alt) to
                                         place freely.
  Drag a segment of a hand-drawn wire    Slides it sideways.
  Double-click a wire                    Adds a point.
  Double-click a handle                  Removes that point.
  Delete or Backspace                    Selected wires go back to automatic.

Every edit is one step in Grasshopper's Undo, and is saved in the file.
While you drag a component, its wires show as Grasshopper curves; they
re-route when you let go.

Changing a style in a file stores it in that file and adds a small "Straight
Wire" component in its top-left corner. That component tells anyone who opens
the file without the plugin what is missing.


UNINSTALL
---------

Delete StraightWire.gha from the folder above and restart Rhino. Files keep
working; their wires are simply drawn as curves again.

SAFE UPDATE / ROLLBACK
----------------------

  Confirm the currently loaded plugin location before replacing files; development
  builds loaded from memory may have no installation path. Save work and quit Rhino.
  Move the old .gha to a backup folder outside Grasshopper Libraries, then copy the
  new .gha into the original location and restart Rhino. Avoid duplicate copies.
  To roll back, quit Rhino, remove the new .gha and restore the backup.
  Building this repository does not install or overwrite a loaded plugin.
